# أذكار المسلم

تطبيق Android عربي احترافي للأذكار، مكتوب بـ Kotlin وJetpack Compose، مع دعم RTL والعمل دون إنترنت للمحتوى الأساسي.

## المميزات

- أذكار الصباح والمساء وغيرها.
- السبحة الإلكترونية.
- المفضلة والبحث.
- التنبيهات المحلية.
- الوضع الليلي وتخصيص المظهر.
- دعم العربية وRTL.
- تخزين محلي للمحتوى والإعدادات.
- مشاركة التطبيق والأذكار.

## تشغيل المشروع

المشروع يستخدم Gradle وAndroid Gradle Plugin.

### من GitHub

بعد رفع المشروع إلى GitHub، افتح تبويب **Actions** ثم شغّل:

**Build Android APK**

سيقوم GitHub Actions ببناء نسخة تجريبية Debug APK تلقائيًا.

بعد نجاح البناء:
1. افتح صفحة الـWorkflow الناجح.
2. انزل إلى **Artifacts**.
3. حمّل `azkar-muslim-debug-apk`.
4. فك الضغط عن الملف وستجد `app-debug.apk`.
5. انقل APK إلى الهاتف وثبّته للتجربة.

> لا ترفع مفاتيح API أو ملفات التوقيع أو `google-services.json` إلى المستودع العام.

## ملاحظات مهمة قبل Google Play

- غيّر `applicationId` من `com.aistudio.azkarmuslim.app` إلى معرّف نهائي فريد قبل النشر.
- ارفع نسخة **AAB** موقعة بمفتاح رفع خاص بك عند تجهيز إصدار المتجر.
- جهّز سياسة خصوصية حقيقية ومعلومات المطور وبيانات متجر Google Play.
- راجع النصوص الدينية ومصادرها قبل الإصدار النهائي.
- لا تضع مفاتيح سرية داخل GitHub.

## البناء المحلي

يمكن استخدام Gradle مباشرة، أو Android Studio إذا كان متاحًا.

لنسخة تجريبية:

```bash
gradle :app:assembleDebug
```

الناتج:

```text
app/build/outputs/apk/debug/app-debug.apk
```
